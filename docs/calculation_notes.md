# Calculation notes

The supplied workbook and report are preserved as the original project materials. The report copy only removes the student identifier. This note records the numerical checks made while preparing the repository. It does not claim that Excel Solver or external data refreshes were executed.

## 1. Return count and sample covariance

The workbook contains 44 closing prices in rows 5–48, giving 43 daily returns in rows 6–48.

The defined name `n` points to `V4`. Its current formula, `COUNT(B5:B48)`, counts prices and returns 44. The covariance matrix formula is `MMULT(TRANSPOSE(X),X)/(n-1)`, where `X` contains the 43 centered return observations. Consequently, the current covariance calculation divides by 43. The asset standard deviations elsewhere use `STDEV.S`, which uses a denominator of 42 for these observations.

For a consistent sample-covariance convention, change `V4` to:

```excel
=COUNT(H6:H48)
```

The displayed counts in `W4:Z4` should likewise count their return columns if they are intended to show the number of return observations. With `n = 43`, the existing matrix formula divides by 42 and its diagonal agrees with the squared sample standard deviations.

## 2. Correlation formula

The current array formula in `V21:Z25` is:

```excel
=SQRT(varcovar/MMULT(TRANSPOSE(stddev),stddev))
```

A correlation coefficient is covariance divided by the product of standard deviations. The square root should be removed. After fixing the sample covariance, the array formula should be:

```excel
=varcovar/MMULT(TRANSPOSE(stddev),stddev)
```

Edit the entire existing array range when needed by the Excel version, rather than attempting to overwrite one member of a legacy array. The resulting diagonal should be 1. For this price snapshot, the NVDA/AAPL correlation is approximately 0.0324 and the MSFT/META correlation is approximately 0.7198. The original report's values of approximately 0.18 and 0.84 therefore need updating, as does its correlation figure.
